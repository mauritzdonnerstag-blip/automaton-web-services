Suggested next checks

How requests work

  1. Submit the URL of a public HTTPS page that you own, manage, or are authorized to request feedback about.
  2. The request is reviewed for suitability before any report is prepared.
  3. If accepted, a preliminary HTML-based report can be produced and checked by a human before it is shared.
Privacy and scope: GitHub Issues and public responses are visible to everyone. Do not include confidential details or personal contact information. This is not a whole-site audit, security test, compliance certificate, or promise of results. This early pilot does not collect payments.
